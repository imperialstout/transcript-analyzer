# People Rolodex

**Purpose:** Working index of named individuals across the program.
Complements (does not replace) the Program Context Brief. The brief
captures stable senior stakeholders with workstream relevance. The
rolodex captures everyone you mention by name twice or more,
including names your transcription tool has mangled, names that
surfaced once with high signal, and names that need confirmation
before they become quotable upward.

**Update rules:**

- Anyone you mention by name twice gets an entry.
- "Stance" and "Watch for" decay fast — revisit monthly. If you
  can't remember why a "watch for" mattered three weeks later,
  delete it.
- One person, one entry. Transcription variants go in the entry, not as
  separate people.
- "TBD" is a real value. Don't make things up to fill fields.
- People in the Program Context Brief get a one-line stub here
  that points back to the brief, not a duplicate full entry.

## How to read this file

Each entry has the same shape:

```
## Name
- **Org / role:**
- **Reports to / works with:**
- **First seen / where:**
- **Stance:**
- **Watch for:**
- **Name variants:** (spellings your transcription tool produces for this person)
- **Notes:**
```

Sections are alphabetical inside each group.

Suggested groups (adapt to your program):
- [Client org] — senior / cross-division
- [Client org] — [Division A]
- [Client org] — [Division B]
- [Your org] — delivery team
- [Your org] — other
- Third parties / vendors
